# Как записать голос, который ElevenLabs примет

Клон повторяет **всё**, что услышит. Гул холодильника, эхо ванной, скачки
громкости — всё это переедет в голос и останется там навсегда, на всех 156
роликах. Переделать клон нельзя, только удалить и записать заново.

Поэтому пять минут на правильную запись экономят день переделок.

## Что принимает ElevenLabs

| | |
|---|---|
| форматы | mp3, wav, m4a, flac, ogg |
| видео | mp4, mov — звук вынимает сам |
| размер | до 10 МБ на файл |
| файлов | до 25 за раз |
| частота | 44.1 кГц, моно |

Формат — мелочь, его я поправлю сам. Важнее то, что ниже.

## Что должно быть в записи

| мерка | норма | почему |
|---|---|---|
| длина | 1–3 минуты | короче 30 секунд — голос плывёт, длиннее трёх минут ничего не добавляет |
| говорящий | один | второй голос модель смешает с первым |
| фон | тишина | музыка и улица въедаются в клон |
| эхо | нет | кафель и пустая комната дают гулкий голос |
| громкость | ровная | без выкриков и шёпота |
| пики | не срезаны | перегруз звучит как треск |

## Где записывать

**Хорошо:** комната с диваном, ковром, шторами, шкафом с одеждой. Мягкое
поглощает эхо. Лучшее место в любой квартире — гардеробная или комната с
плотными шторами.

**Плохо:** кухня, ванная, коридор, пустая комната, машина с работающим
двигателем, улица, кафе.

Перед записью выключи кондиционер, вытяжку, телевизор. Холодильник даёт
ровный гул, который слышно только на записи — если можно, выключи и его.

## Как держать телефон

```
расстояние      ладонь от рта, около 20 см
направление     микрофоном к себе, не в стол
дыхание         не дыши прямо в микрофон, говори чуть мимо
руки            не перекладывай телефон во время записи
```

Расстояние не менять: каждое приближение и отдаление модель считает
изменением голоса.

## Что говорить

Не читай по бумажке ровным голосом — клон выйдет таким же деревянным.
Говори живо, как объясняешь другу.

Лучший вариант: **начитай тексты своих же роликов**. Тогда модель услышит
именно ту интонацию, которая нужна в рекламе, а не нейтральное чтение.

Три-четыре ролика подряд как раз дадут нужные полторы минуты.

Полезно включить в запись:
- вопрос с вопросительной интонацией
- перечисление через запятую
- призыв в конце, бодро

## Проверка перед загрузкой

Кинь запись в Загрузки и запусти:

```bash
/Volumes/T7/reels-saas/.venv/bin/python /Volumes/T7/reels-saas/proverit_obrazec.py ~/Downloads/запись.m4a
```

Он померит запись по шести меркам и скажет либо «ГОДИТСЯ», либо что именно
переписать. Проверка занимает секунду и экономит день.

Пример разбора настоящей записи из TikTok:

```
ПЛОХО   длина        25.7   норма 60-180 секунд
хорошо  перегруз      0.0   норма 0-0.5 %
ПЛОХО   шум          10.4   норма 35-99 дБ
ПЛОХО   эхо           0.6   норма 0-0.45
хорошо  ровность      2.5   норма 0-6.0 дБ
хорошо  речь         78.9   норма 45-95 %
```

Такую запись клонировать нельзя: шума почти столько же, сколько речи, и
слышно помещение.

Для сравнения, чистая студийная запись:

```
шум          76.3      эхо          0.1
```

Разница в шестьдесят децибел — вот что значит «чисто».

## Приведение к нужному формату

Если проверка прошла, привожу файл к виду, который ElevenLabs любит:

```bash
/Volumes/T7/reels-saas/podgotovit_golos.sh ~/Downloads/запись.m4a
```

Скрипт делает моно 44.1 кГц, срезает гул ниже голоса, убирает ровный шум и
выравнивает громкость. **Сжатие сознательно не трогает**: компрессор прячет
характер голоса, и клон выходит плоским.

## Чей голос можно клонировать

| | |
|---|---|
| свой | да |
| сотрудника, с его согласия | да |
| диктора, которому заплатил | да |
| из TikTok, Instagram, YouTube | нет |

Это правило самого ElevenLabs, не моё. За чужой голос блокируют аккаунт
вместе с оплаченной подпиской, а претензии пострадавшего идут к владельцу
сервиса.

Наёмный диктор на Kwork или Fiverr стоит около десяти тысяч тенге за час
работы, и права на запись переходят к тебе. Один раз заплатил — голос твой
на все годы вперёд.
