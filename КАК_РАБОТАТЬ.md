# ibook Studio — твоя студия роликов

Свой генератор промо-видео для ibook. Работает на твоём Mac. Подписок не требует.

## Сколько это стоит в месяц

| что | чем делаем | цена |
|---|---|---|
| кадры | сток Pexels | 0 ₸ |
| монтаж, музыка, сведение | ffmpeg у тебя на Mac | 0 ₸ |
| голос: 11 языков | локальная модель Chatterbox | 0 ₸ |
| голос: казахский | ElevenLabs | единственная платная строка |

Казахский пока платный: у бесплатной модели нет казахского языка. Как только
проверю `KazakhTTS-OmniVoice` — уйдёт и он, и подписка станет не нужна совсем.

## Команды

Всё через один файл. Из папки `~/reels-saas`:

```bash
.venv/bin/python studio.py языки
```
Покажет таблицу: какой язык, для какой страны, сколько сценариев готово и чем
считается голос — платно или бесплатно.

```bash
.venv/bin/python studio.py ролик ru 31 A
```
Один ролик. `ru` — язык, `31` — неделя года, `A` — какой из трёх роликов недели.

```bash
.venv/bin/python studio.py неделя 31
```
Одна неделя на всех 12 языках сразу.

```bash
.venv/bin/python studio.py год uz
```
Весь год на одном языке: 156 роликов подряд. Каждый готовый сразу уходит тебе
в Telegram с подписью «АВГУСТ · ролик 4 из 15», чтобы ты не путался в номерах.
Считает от текущего месяца, а не с января. Если прервёшь — при следующем
запуске продолжит с места остановки, готовое заново не пересчитывает.

```bash
.venv/bin/python studio.py проверь /Volumes/T7/ibook/video/год-русский
```
Контроль качества. Ловит два бага, которые на глаз не видно:
картинка замирает раньше звука, и разные ролики начинаются одним кадром
(Instagram считает такие дублями и режет охват).

## Переключатели

```bash
ENGINE=local  .venv/bin/python studio.py год kk    # вообще всё бесплатно
ENGINE=eleven .venv/bin/python studio.py год ru    # всё на платном, быстрее
```

## Где что лежит

| файл | зачем |
|---|---|
| `studio.py` | единственная точка входа, все команды здесь |
| `reel_engine.py` | сборка ролика: кадры, голос, музыка, кодек |
| `year_batch.py` | прогон целого года + отправка в Telegram |
| `cta_lines.json` | финальный призыв по языкам — правь руками |
| `~/ibook-video/videos_*.json` | сами сценарии на год |
| `~/uz-tts/` | локальная модель голоса |
| `/Volumes/T7/ibook/video/` | готовые ролики (на внешнем диске) |

## Что важно помнить

- Внешний диск T7 должен быть подключён: год роликов это несколько гигабайт,
  на встроенном диске столько нет.
- Ноутбук во время прогона не должен засыпать, иначе счёт встанет:
  `caffeinate -dimsu` в отдельном окне терминала.
- Ролики без субтитров и надписей — так и задумано, призыв звучит голосом.
- Бренд везде произносится «Айбук», в том числе по-китайски и по-французски.
  Написание на экране не меняется — всегда `ibook`.
